# Asta Powerproject feature inventory, part 1: bar chart, views and tables, printing and output, Library Explorer

Research date: 2026-11-21. Sources are the official Asta Powerproject online help (help.elecosoft.com, current release, 2026.x), the help's "What's new" page, the release notes site (15.0.01, 16.0.x, 17.x, 2026.1), Eleco/Elecosoft news and documentation tip pages, and the official Powerproject tutorial help. The help uses "bar" for a row in the chart and "task" for a piece of work drawn on a bar; one bar can carry several tasks. Ribbon paths are given as the help states them (tab > group > command). "Verified" means I read the feature on the cited page; "unverified" means the feature is mentioned only in a search snippet, a marketing page or not found at all. Descriptions are paraphrased.

## Ten features the documentation itself presents as signature strengths in these areas

1. Several tasks on one bar line, with one-task-per-line expansion, roll-up/unroll and overlapping "unit networks" (A4-A9). Eleco's own tips and the features page ("compact layouts show overlapping tasks") lead with this.
2. Draw-and-drag planning: tasks, links, moves, copies and resizes are all mouse gestures with snapping, Link Tasks mode and block linking (A1, A2, A11-A20).
3. Code libraries as the single mechanism for colouring, filtering, sorting, grouping and code breakdown structures, with multi-library priority display (A29, B43-B48).
4. Filters with a wizard and a SQL-like TQL language, savable into views, combinable, and reusable for selection, annotations, reports and look-aheads (B36-B41, A25, A63).
5. Sort/group with subheadings, banding, date bucketing (look-ahead by week) and automatic page breaks (B31-B35).
6. Named views that bundle table, filter, sort, bar chart format, scope and print profile, with categories, coloured tabs, tiling and Project Viewer sharing (B1-B9, C29).
7. Formula-driven spreadsheet columns and bar text, with a guided Formula Properties editor (B26-B27, A32).
8. Date zone flexibility: up to three timescale sections, variable-date shading and grid lines, folding of non-working time, progress in the header (A40-A53).
9. Border files and Powerdraw title blocks with live data fields, embedded borders, Vision download, legends, tiled/paginated output and fit-to-page scaling (C6-C19).
10. Library Explorer as the hub for 37 object libraries, with spreadsheet-style editing, drag-and-drop assignment and pasting of lists from Excel (D1-D8).

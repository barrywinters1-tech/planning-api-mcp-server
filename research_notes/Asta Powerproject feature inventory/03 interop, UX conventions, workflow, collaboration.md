# Asta Powerproject feature inventory — 03: interoperability, UX conventions, workflow, collaboration

Compiled 2026-11-21 from public Elecosoft/Eleco documentation (Powerproject online help, tutorial, release notes, product pages, training outlines) plus a small number of reputable third-party write-ups where they describe features concretely. Nothing below is copied verbatim; every row is a paraphrase of what the cited page documents. The help site currently documents Asta Powerproject 2026.3 (internal build 18.2.01); where a feature arrived in 15, 16 or 17 the version is noted.

Confidence scale:
- **High** — behaviour stated on an Elecosoft help/tutorial/release-notes page that was fetched and read.
- **Medium** — stated on an Elecosoft marketing/training page or a reputable third-party article, or only partially documented.
- **Unverified** — commonly asserted but no public Elecosoft page could be found confirming it; treat as a gap.

Help URL stems used repeatedly (abbreviated in the tables as `HELP/…`, `TUT/…`, `RN/…`):
- `HELP/` = `https://help.elecosoft.com/powerproject/english/help/Content/HTML_Topics/`
- `TUT/` = `https://help.elecosoft.com/powerproject_tutorial/english/help/Content/HTML_Topics/`
- `RN/` = `https://help.elecosoft.com/powerproject_release_notes/english/Content/HTML%20Topics/`

## Conventions a planner would expect any Asta-like tool to honour

Behavioural conventions, each tied to the page that documents it. (A tool that calls itself "Asta-like" and breaks one of these will feel wrong to a Powerproject planner.)

1. **Double-click toggles structure, not properties.** Double-clicking a summary task opens/closes its group; double-clicking an expanded task drills into its subchart; *Up one level* on the Quick Access toolbar returns. — `HELP/Conceptual/Structuring_your_project/Working_with_summary_tasks/Opening_and_closing_summary_tasks.htm`; `TUT/Structuring_a_project_using_expanded_tasks.htm`
2. **Properties come from right-click > Properties (or SHIFT F2 / ALT ENTER)**, opening the Bar and Task Properties dialog with Bar and Task tabs and *More >>* for Allocations/Links/Relations; the docked properties view mirrors it. — `HELP/Dialogs/D_Bartaskprop.htm`; `HELP/Conceptual/Keyboard_shortcuts/View_shortcuts.htm`
3. **Dragging the body of a task moves it in time, keeping its duration**; the cursor changes to the "sweet-wrapper" shape over the body. — `HELP/Conceptual/Starting_work/Moving_bars_and_tasks/Moving_bars_and_tasks_horizontally.htm`
4. **Dragging an end of a task changes only that date (so the duration)**; the cursor becomes a bracket, and a popup shows start, finish and duration while dragging. — `HELP/Conceptual/Starting_work/Changing_the_duration_of_tasks/Changing_the_duration_of_tasks.htm`; `TUT/Changing_the_dates_of_tasks.htm`
5. **Shrinking a task to zero duration turns it into a milestone**, and right-click > Make Into > Task turns it back. — `HELP/Conceptual/Starting_work/Changing_the_duration_of_tasks/Changing_the_duration_of_tasks.htm`
6. **Vertical drag moves a task to another bar; SHIFT keeps its dates; CTRL on release copies**; right-button drag offers Move / Copy / Move Here Keep Same Dates / draw links / Cancel. Dropping below the last bar creates the bars needed. — `HELP/Conceptual/Starting_work/Moving_bars_and_tasks/Moving_bars_and_tasks_vertically.htm`
7. **ALT-click selects a whole bar**, and moving one task on it then moves every task on the bar together. — `HELP/Conceptual/Starting_work/Moving_bars_and_tasks/Moving_bars_and_tasks_horizontally.htm`
8. **Tasks on one bar do not overlap by default — dropping onto them shunts them along** (unless the bar is set to allow overlap, or they are summary/expanded tasks). — same page; `HELP/Dialogs/D_Bartaskprop.htm` (*Tasks may overlap*)
9. **Everything snaps to the Snapping Time Unit** (View > Show); working units snap back to the last working period rather than landing on a weekend. — `HELP/Conceptual/Starting_work/Creating_bars_and_tasks/Bar_chart_snapping.htm`
10. **A task is drawn by pressing and dragging horizontally on an empty part of a bar**; vertical movement is ignored; the name is typed in the spreadsheet; a second drag to the right adds another task to the same bar. — `TUT/Creating_tasks.htm`; `TUT/Creating_multiple_tasks_on_the_same_bar.htm`
11. **A link is drawn by dragging from the top/bottom edge of the predecessor (near its start or end) onto the successor**; the cursor indicates which end you are linking, giving FS/SS/FF/SF; releasing off a task abandons the link; the arrowhead sits at the successor. — `HELP/Conceptual/Starting_work/Linking_tasks/Linking_tasks.htm`; `TUT/Linking_tasks.htm`
12. **Right-click on a link offers Properties and Delete**; DELETE removes a selected link; dragging a selected link's end re-attaches it to another task or point. — `HELP/Conceptual/Starting_work/Linking_tasks/Deleting_links.htm`; `HELP/Dialogs/D_Linkprop.htm`; `HELP/Conceptual/Starting_work/Linking_tasks/Moving_links.htm`
13. **Link Tasks mode (CTRL F3) auto-links each task as it is drawn or selected (FS; hold F for FF)**, and *Link Tasks* block-links a selection top-down with FS. — `HELP/Conceptual/Starting_work/Linking_tasks/Link_Tasks_mode.htm`; `HELP/Conceptual/Starting_work/Linking_tasks/Block-linking_tasks.htm`
14. **Predecessor/Successor columns accept typed logic** in the form `identifier (category) TYPE lag` (e.g. `A SS 2d`), with comma separators. — `HELP/Conceptual/Starting_work/Linking_tasks/Link_spreadsheet.htm`
15. **Progress is always recorded against a progress period with a report date**; the *progress entry period* is set by right-click in the project view (red tick), old periods are *Locked* (padlock), and completed sections shade in that period's colour. — `HELP/Conceptual/Progress/Using_progress_periods/Using_progress_periods.htm`; `TUT/Reporting_progress_against_tasks.htm`
16. **Progress can be entered directly on the chart by dragging across the task body in Progress Entry Mode** (sets duration % complete), or via the Object Edit % control, the Percent complete column, or the Enter Progress dialog; milestones are only 0 % or 100 %. — `HELP/Conceptual/Progress/Marking_progress/Marking_progress_directly.htm`; `TUT/Reporting_progress_against_tasks.htm`
17. **The progress line stays jagged until an explicit Reschedule (F9 / Home > Schedule), which straightens it to the report date and pushes uncompleted work to the right.** — `TUT/Reporting_progress_against_tasks.htm`; `HELP/Conceptual/Rescheduling_projects/Setting_reschedule_options/Setting_reschedule_options.htm`
18. **Right-click on the date zone gives Properties, Insert Line, Hide This Line and Start New Scale Zone**; dragging its red vertical lines rescales; dragging an empty area scrolls; ALT-drag pans the chart with a hand cursor. — `HELP/Conceptual/Setting_up_the_bar_chart/Using_the_date_zone/Edit_date_zone_directly.htm`; `TUT/Formatting_the_date_zone.htm`; `HELP/Conceptual/Setting_up_the_bar_chart/Moving_around_the_bar_chart/Moving_around_the_bar_chart.htm`
19. **Dragging a library object (calendar, code, resource, cost, progress period, milestone appearance) from the project view or Library Explorer onto a task assigns it**; right-click *Assign …* menus do the same. — `HELP/Other/S_Projectview.htm`; `HELP/Conceptual/Calendars/Assigning_calendars/Assigning_calendars.htm`
20. **Dragging a task pool (or a subchart/summary group inside it) from the project view into the bar chart inserts that network as a summary/expanded task starting at the date under the cursor.** — `HELP/Conceptual/Task_pools/Task_pools_using.htm`
21. **The + / − beside a bar number switches that bar between bar-per-line and one-task-per-line**; in bar mode the spreadsheet summarises the bar's first start, total duration and last finish. — `HELP/Conceptual/Starting_work/Entering_bar_and_task_names/Working_in_one_task_per_line.htm`; `TUT/Creating_multiple_tasks_on_the_same_bar.htm`
22. **Right-click in the Line column inserts a bar above that row**, and right-click on a column heading adds (to the left), replaces or removes a column. — `TUT/Moving_and_inserting_bars.htm`; `HELP/Conceptual/Spreadsheet/Editing_the_spreadsheet/Adding_columns_to_the_spreadsheet.htm`
23. **Baselines draw as separate bars beneath the live tasks** (default yellow), toggled with Format > Show/Hide > Baselines (ALT SHIFT B), managed from Project > Baseline Manager; the ticked baseline is *current* and drives variance columns. — `TUT/Baselining_projects.htm`; `HELP/Conceptual/Setting_up_the_bar_chart/Setting_display_options/Display_switches.htm`
24. **Display overlays toggle with ALT+SHIFT+letter** (C critical path, F free float, T total float, L all links, K non-driving links, B baselines, G grid lines, N annotations). — `HELP/Conceptual/Setting_up_the_bar_chart/Setting_display_options/Display_switches.htm`
25. **Each view is a tab that remembers its table, filter, sort/group, bar-chart format and divider positions**; Home > Tab > New Tab opens another tab on the same project, CTRL TAB cycles, and the status bar shows (and clears on click) the active filter and sort. — `HELP/Conceptual/Views/Introduction_to_views/Introduction_to_views.htm`; `HELP/Other/S_Status_bar.htm`; `https://help.elecosoft.com/project_viewer/english/help/Content/HTML_Topics/Conceptual/Views/Opening_windows_onto_a_project.htm`
